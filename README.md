# FrontLoaded-AIDD-Toolkit
A lightweight, open-source Python toolkit designed to support front-loaded synthetic accessibility scoring, reactivity evaluation, and Pareto-optimal multi-objective filtering for AI-Driven Drug Discovery (AIDD).

## Installation
```bash
git clone [https://github.com/你的用户名/FrontLoaded-AIDD-Toolkit.git](https://github.com/你的用户名/FrontLoaded-AIDD-Toolkit.git)
cd FrontLoaded-AIDD-Toolkit
pip install rdkit numpy scikit-learn
